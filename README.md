# Nitro (ナイトロ)

> Search at the speed of thought. Fueled by coffee.

Nitroは、PC内のファイルやコードスニペット、起動中のアプリを瞬時に検索し、キーボードやマウス操作で目的の情報へ到達するための高速ローカル検索ランチャーです。開発者の日常作業を中断しない検索体験を提供することを目的としています。

## 主な機能 (MVP Phase 1)

*   **モード切替:** UI上のボタン、または `Tab` / `Shift+Tab` キーで「アプリ切替」「ファイル検索」「スニペット」のモードを切り替え可能。
*   **アプリ切替 (App Launcher):** 現在起動中のアプリケーションのウィンドウを一覧表示・検索し、選択したウィンドウを瞬時に最前面へフォーカスします。
*   **高速ファイル検索:** 指定したディレクトリ（設定画面から複数指定可能）内のファイルを高速に検索します。右クリックメニュー「既定のアプリで開く」にも対応。
*   **スニペット管理:** よく使うコードスニペットやテキストを保存し、タグで検索してクリップボードにコピーできます。
*   **グローバルショートカット:** `Ctrl+Space`（または設定したキー）でいつでもどこでも検索ウィンドウを呼び出せます。
*   **洗練されたモダンUI:** フラットでシャドウを抑えた没入感のあるデザイン。スクロールバーも細くカスタマイズされています。
*   **カスタマイズ可能な設定:** ショートカットキーの変更、テーマカラー（全10色）、検索対象ディレクトリの指定がUIから行えます。
*   **フル操作サポート:**
    *   キーボードの上下矢印キー、および **マウスのスクロールホイール** でのリスト選択。
    *   `Enter` キーによるファイルのオープン（OS標準のアプリケーションで確実かつ安全に開きます）。

## 技術スタック

*   **フロントエンド:** Svelte 5 (SvelteKit), Tailwind CSS v3 (Zincベースのモダンテーマ), shadcn-svelte, bits-ui, lucide-svelte
*   **バックエンド:** Rust, Tauri v2
*   **コア機能:**
    *   `walkdir` (高速再帰的ファイル検索)
    *   `open` (OS既定アプリでのファイル展開)
    *   `x-win` (クロスプラットフォームなアクティブウィンドウ取得)

## セットアップとビルド方法

このプロジェクトをローカルでビルド・開発するための手順です。Node.js と Rust (Cargo) の環境が必要です。

```bash
# リポジトリのクローンとディレクトリへの移動
cd nitro

# 依存関係のインストール
npm install

# 開発サーバーの起動 (ホットリロード対応)
npm run tauri dev

# プロダクションビルドの作成
npm run tauri build
```

## 使い方

1.  アプリケーションを起動すると、システムトレイに常駐します。
2.  `Ctrl+Space`（デフォルト）を押すと、画面中央に検索パレットが表示されます。
3.  **モード切り替え:** `Tab` キーを押すか、検索窓の下にあるボタンをクリックしてモード（アプリ、ファイル、スニペット）を切り替えます。
4.  **ファイル/アプリ検索:** キーワードを入力すると該当項目が絞り込まれます。マウススクロールまたは矢印キーで選択し、`Enter` で実行（アプリのフォーカス、またはファイルを開く）します。
5.  **スニペット登録:** 検索窓の横にある「➕ (Plus)」ボタンをクリックし、タイトル、内容、タグを入力して `Ctrl+Enter` または「OK」ボタンで保存します。
6.  **設定変更:** 検索窓の横にある「歯車」アイコンをクリックすると、起動ショートカットやテーマカラー、検索対象ディレクトリ（改行区切りで複数指定可能）を変更できます。
